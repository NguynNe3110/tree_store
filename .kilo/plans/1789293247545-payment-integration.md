# Payment Integration Plan

## Overview
- **Payment Type**: VNPayQr/MomoQr
- **Backend**: Kotlin + Ktor
- **App**: Flutter + Dio
- **Status Update**: Polling API backend

## Backend Changes
### API Endpoints
1. **Generate QR Code**
   - Endpoint: `POST /api/payment/qr`
   - Request Body: `{ orderId: String, amount: Double }`
   - Response: `{ qrCodeUrl: String, orderId: String }`

2. **Check Payment Status**
   - Endpoint: `GET /api/payment/status/{orderId}`
   - Response: `{ status: "pending" | "success" | "failure", orderId: String }`

### Implementation
- Add mock logic in `Routes.kt`:
  ```kotlin
  fun Route.paymentRoutes() {
      route("/api/payment") {
          post("/qr") {
              val req = call.receive<PaymentQrRequest>()
              val qrCodeUrl = "https://mock-vnpay.com/qr?orderId=${req.orderId}&amount=${req.amount}"
              call.respond(PaymentQrResponse(qrCodeUrl, req.orderId))
          }
          get("/status/{orderId}") {
              val orderId = call.parameters["orderId"]!!
              val status = if (orderId.startsWith("success_")) "success"
              else if (orderId.startsWith("failure_")) "failure"
              else "pending"
              call.respond(PaymentStatusResponse(status, orderId))
          }
      }
  }
  ```

## App Changes
### Network Layer
- Add Dio service for payment:
  ```dart
  class PaymentService {
      final Dio dio;
      
      PaymentService(this.dio);
      
      Future<Map<String, dynamic>> generateQrCode(String orderId, double amount) async {
          final response = await dio.post("/api/payment/qr", data: {
              "orderId": orderId,
              "amount": amount,
          });
          return response.data;
      }
      
      Future<Map<String, dynamic>> checkPaymentStatus(String orderId) async {
          final response = await dio.get("/api/payment/status/$orderId");
          return response.data;
      }
  }
  ```

### State Management
- Add payment state to `PaymentBloc`:
  ```dart
  class PaymentState {
      final String? qrCodeUrl;
      final String? paymentStatus;
      final String? error;
      
      PaymentState({this.qrCodeUrl, this.paymentStatus, this.error});
  }
  ```

### UI Logic
- Add polling logic in `PaymentScreen`:
  ```dart
  void _checkPaymentStatus() async {
      final status = await paymentService.checkPaymentStatus(orderId);
      if (status["status"] == "success") {
          // Update UI and navigate to success screen
      } else if (status["status"] == "failure") {
          // Update UI and navigate to failure screen
      } else {
          // Retry after delay
          Timer(const Duration(seconds: 5), _checkPaymentStatus);
      }
  }
  ```
